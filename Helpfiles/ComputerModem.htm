HEX and XMODEM Support

HEX or XMODEM file transfer is available when the selected XML file includes a HEX or XMODEM definition.

HEX Support

The main controls for HEX Support are shown in the screenshot below. The numbered markers in the screenshot correspond to the descriptions in this section.

  • (1) HEX button
  • (2) HEX text field (selected file)
  • (3) Eject button
  • (4) Auto checkbox
  • (5) Turbo checkbox
  • (6) Play button
  • (7) Stop button
  • (8) Record button
  • (9) CPU speed field (MHz)

A HEX file can be loaded in configurations such as COSMAC Elf 2000 (when using a terminal), CDP18S020 Evaluation Kit, Membership Card, and VIP2K Membership Card.

Press the HEX button (1) and select a file.
Result: The selected file is shown in the HEX text field (2).

Press the Eject button (3).
Result: The selected file is cleared.

Note: The default and simplest method is Auto file transfer (4). For faster transfer, select the Turbo checkbox (5).

Workflow

Select File     : Press the HEX button
Start Transfer  : Auto file transfer or press the Play or Record button
Stop Transfer   : Press the Stop button
Turbo Mode      : Enable for faster transfer

Elf 2000 (Manual only)

Clear the Auto checkbox (4).

apply all

Start a COSMAC Elf 2000 emulator.
Result: The COSMAC Elf 2000 monitor starts and shows the >>> prompt.

Loading

Press the Play button (6).
Result: HEX data is shown on the terminal window.

When the last line shows >>>:00000001FF, press RETURN; EOF is shown, indicating the end of the file.

Press the Stop button (7) to stop the transfer.

CDP18S020 Evaluation Kit (Manual only)

Clear the Auto checkbox (4).

Start a CDP18S020 Evaluation Kit emulator.
Press RETURN.
Result: The UT4 monitor starts and shows the * prompt.

Loading

Command: Type !M.

Press the Play button (6).
Result: Unreadable data is shown on the terminal window.

When terminal output stops, press the Stop button (7) to end the transfer.

Saving

Command: Type ?M<start> <length>.

Press the Record button (8) and then press RETURN.
Result: Output data is shown on the terminal window.

When terminal output stops, press the Stop button (7) to end the transfer.

Membership Card and VIP2K Membership Card

HEX file transfer for the Membership Card and VIP2K Membership Card uses the monitor software. All files transferred via the monitor must be in Intel HEX format (.hex extension).

Important: Raw binary files (e.g., .ch8 or .bin) cannot be used directly. They must first be converted to Intel HEX format.

Start a Membership Card emulator.
Result: The Membership Card monitor starts and shows the > prompt.

Monitor Commands

  • L â€” Load a program (Intel HEX file loaded to address specified in the HEX file)
  • I â€” Load a Chip-8 program (Intel HEX file loaded to the Chip-8 memory area)
  • S â€” Save a program

Note: Both L and I use the Intel HEX protocol. The difference is that I sets the destination to the Chip-8 memory area before loading.

Auto LOAD/SAVE

Command: Press L to load a program or I to load a Chip-8 program.

Command: Press S to save.

Note: For the Membership Card: when save is finished the front panel LEDs flash; press a key in the terminal window.

Note: Make sure a file is selected (2). Otherwise, the emulator may hang or no file will be written.

Manual LOAD/SAVE

Clear the Auto checkbox (4).

Loading

Command: Press L to load a program or I to load a Chip-8 program.
Result: Terminal shows Ready to LOAD Program.

Press the Play button (6).
Result: The selected file is loaded.

Saving

Command: Press S to save.
Result: Terminal shows Ready to SAVE Program.

Press the Record button (8).
Result: The selected file is saved.

Note: For the Membership Card: when save is finished the front panel LEDs flash; press a key in the terminal window.

Turbo file transfer

Select the Turbo checkbox (5).
Result: Emulator CPU speed is increased during file transfer.

Note: Default speed is 15 MHz (9); higher values may be used on faster systems.

Important: Values that are too high may cause performance issues on slower systems.

XMODEM Support

The main controls for XMODEM Support are shown in the screenshot below. The numbered markers in the screenshot correspond to the descriptions in this section.

  • (1) XMODEM button
  • (2) XMODEM text field (selected file)
  • (3) Eject button
  • (4) Auto checkbox
  • (5) Turbo checkbox
  • (6) Play button
  • (7) Stop button
  • (8) Record button
  • (9) VT Setup button

Press the XMODEM button (1) and select a file.
Result: The selected file is shown in the XMODEM text field (2).

Press the Eject button (3).
Result: The selected file is cleared.

Note: The default and simplest method is Auto file transfer (4). For faster transfer, select the Turbo checkbox (5).

Workflow

Select File     : Press the XMODEM button
Start Transfer  : Use xr/xs/yr/ys commands
Manual Mode     : Use Play / Record buttons
Stop Transfer   : Press the Stop button

Auto file transfer

Select the Auto checkbox (4).

Command: Type xr, xrb, xs, xsb, yr or ys in Elf/Os.

Note: For xr, xrb, xs, xsb, only one file is used.

Note: The yr command supports multiple files.

Note: The ys command uses filenames defined in Elf/Os.

Note: If no file is selected, Elf/Os will wait. Clear the Auto checkbox (4) and use manual transfer.

Manual file transfer

Clear the Auto checkbox (4).

Command: Start the file transfer command in Elf/Os.

Press the Play button (6) to send the file to Elf/Os.
Result: The selected file is loaded.

Press the Record button (8) to receive a file from Elf/Os.
Result: The selected file is saved.

Press the Stop button (7) to stop the transfer.

Turbo file transfer

Select the Turbo checkbox (5).
Result: Emulator CPU speed is increased during file transfer.

Note: Default speed is 15 MHz; higher values may be used on faster systems.

Important: Values that are too high may cause performance issues on slower systems.

YMODEM Receive (yr) Packet Size

Press the VT Setup button (9).
Result: The VT Setup window opens, where the packet size can be set to Auto, 1024, or 128.

Note: Auto uses 1024 bytes when possible, and 128 bytes otherwise.

For details, see the Terminal Setup section.
