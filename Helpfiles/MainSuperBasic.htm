Quest Super BASIC

For Super Basic copyright information please see the Copyright section below.

To start Quest Super Basic, load one of the Super BASIC XML files in the Elf directory.

For version 1.4, the Super Video option will configure the Elf computer with a Super Video and the Serial option will configure the Elf computer with a serial VT100 terminal. To start Super Basic 1.4 on the VT100 use the following:

  • Press the IN button (Insert)
  • While keeping the IN button pressed, press 'G' or the RUN switch (both emulated by F12)
  • Release the IN button
  • Press Return to allow BASIC to determine the defined baud rate (max 2400)
  • Press 'C' for a cold start and 'W' for a warm start.

To start Super Basic on Super Video (1.4, 3.0, 5.0 and 6.0) just press 'C' for a cold start and 'W' for a warm start.

Super Basic emulation supports loading program and data files with .super extension as described in the Memory Access section.
