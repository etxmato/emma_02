The RCA CDP1802

The RCA CDP1802 is an 8-bit CMOS microprocessor introduced by RCA in early 1976. COSMAC is an acronym for Complementary Silicon Metal-Oxide Conductor and was RCA's name for its CMOS semiconductor technology. The CDP1802 has an architecture quite different from most other 8-bit microprocessors. The RCA CDP1802 is the one-chip implementation of the earlier two-chip RCA CDP1801.

RCA also produced the RCA CDP1804 microcontroller based on the RCA CDP1802 architecture. The CDP1804 had 64 bytes of RAM, 2 KB ROM, an on-chip oscillator, and an 8-bit timer. The instruction set of the CDP1804 was enhanced with 32 additional instructions, including subroutine call and return instructions. The RCA CDP1805 and RCA CDP1806 were similar to the CDP1804, but they did not have on-chip ROM.

The first known prototype of the RCA CDP180x family is a chip set called the RCA SYSTEM00 used in the FRED I. The SYSTEM00 chip set uses a subset of the CDP1801 instruction set with some incompatible differences and is likely the basis for the later CDP1801.

Notable Characteristics of the RCA CDP1802

The RCA CDP1802 has several architectural features that distinguish it from many other 8-bit microprocessors of the same era.

No Minimum Clock Speed

The RCA CDP1802 uses a fully static CMOS design and therefore has no minimum clock frequency. The clock can be slowed down significantly or even stopped completely without losing the processor state. Execution can resume when the clock is restarted.

Because of this property, early COSMAC systems could run at extremely low speeds, and some systems even allowed manual stepping of the CPU clock for debugging or demonstration purposes.

Register-Based Program Counter

The register set of the CDP1802 consists of sixteen 16-bit registers (R0-R15). Unlike most other microprocessors, any of these registers can act as the program counter. The instruction SEP Rx selects which register is used as the program counter.

This allows simple implementation of multiple program counters, pointers, and lightweight task switching.

Simple Interrupt Structure

The interrupt system of the CDP1802 is intentionally simple. When an interrupt occurs, the processor stores the current program counter register number and begins execution using register R1 as the program counter. Software is responsible for saving and restoring the processor context if required.

Q Output and EF Inputs

The CDP1802 provides a single programmable output line called Q and four external flag input lines called EF1-EF4. These signals are frequently used for simple I/O operations, bit-level communication, or status monitoring in COSMAC-based systems.

Multiplexed Address Bus

Although the processor supports a 16-bit address space, it uses an 8-bit physical address bus. The high-order byte and the low-order byte of the address are placed on the bus in separate clock cycles. This multiplexed addressing simplifies the hardware design but requires additional cycles for memory access.

Use in High-Reliability Systems

Due to its static CMOS design, low power consumption, and tolerance to radiation, the RCA CDP1802 was widely used in spacecraft and other high-reliability applications.
