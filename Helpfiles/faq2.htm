How do I load software from an old tape into Emma 02?

There are two ways to load software from a tape into Emma 02 and save it on your hard disk in binary, hex, or other formats:

  1. First convert the tape to a WAV file and then load the WAV file as described in the Cassette Support section.
  2. Load the tape in real time into Emma 02 via your PC hardware as described in the Real Cassette Support section.

Both options are described in more detail on the Tape Conversion page on the Emma 02 website.
