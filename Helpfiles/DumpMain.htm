Memory Dump

The Memory Dump tool shows 256 bytes of memory in the GUI in both hexadecimal format and as ASCII characters. Multiple memory options are available, including CPU memory, video memory, memory type information, and profiler data.

The main elements of the Memory Dump tab are shown in the screenshot below.

  • (1) Memory Dump tab
  • (2) Byte values display
  • (3) ASCII characters display
  • (4) Page navigation spin buttons
  • (5) Address text field
  • (6) Memory type selector

To open this tab, select the Memory Dump tab (1).

The default view shows the first 256 bytes of main CPU memory from the emulated computer, displaying byte values (2) and the corresponding ASCII characters (3) for each memory location. To change to the previous or next page, use the Page navigation spin buttons (4). Alternatively, specify an Address in the text field (5).

To change any memory value (2), select the value and modify it directly. Both ROM and RAM values can be changed.

If the text No emulation running is shown, it indicates that no emulator is active. In this state, the data shown is not active and changing the address value will have no effect.

When running an emulation using the RCA CDP1870, the actual shaped video characters are shown. Other video emulations display ASCII characters (3).

Additional memory views are available by changing the Memory selection button (6). Available Memory Dump options include:

  • CPU: Default view showing CPU-accessible memory locations.
  • Type: Memory types defined for main CPU memory. See the Memory Type section.
  • Profiler: See the Profiler section.
  • 1870 Page: RCA CDP1870 page memory.
  • 1870 Character: RCA CDP1870 character memory. For the Telmac TMC-600, the character ROM is shown, and for both TMC-600 and Cidelsa only 6 bits are used.
  • 1870 Colour: RCA CDP1870 colour RAM, used by the Telmac TMC-600 and Cidelsa. The TMC-600 uses one nibble (4 bits) to define colour and blink mode of the character in the same location in page memory. The Cidelsa uses 3 bits to define the colour of the character and line in the same location in character memory.
  • 1870 Graphic: RCA CDP1870 graphic RAM, used only by the VIS1802.
  • 6845 Character: MC6845 character ROM.
  • 6847 Character: MC6847 character RAM. Both internal and external ROMs are shown; internal from hexadecimal address 0 to 1FF and external from 200 to 7FF.
  • 6847 Video RAM: The first half shows bits 0 to 7 and the second half bits 8 to 11.
  • TMS Video RAM: Only 16384 addresses are viewable.
  • VT Video RAM: VT50/VT100 video RAM.
  • 1862 Colour RAM.
  • 1864 Colour RAM.
  • Studio IV Colour: Studio IV-specific colour RAM.
  • 8275 Character: Intel 8275 character RAM.
  • 8275 Video RAM: Intel 8275 video RAM.
  • VIP2K Video Sequencer: VIP2K Membership video sequencer ROM.
  • RTC RAM: Elf 2000 and Pico/Elf V2 RTC RAM.

In all modes except Type and Profiler, memory values are shown and can be modified per memory page of 256 bytes. In Type mode, memory types (ROM, RAM, Video RAM, etc.) are shown and can be changed.

The following additional features are available on Windows and OS X (currently not implemented in the Linux version): after editing one byte, the next address is selected automatically. After the last byte of a page is changed, the next page is shown.

Note: When using any of the video modes above, only the addresses in use are shown. The number of addresses depends on the emulated computer and video settings.

Note: None of the settings in the Memory Dump tab are saved in the Emma 02 configuration. Each time the emulator starts, these settings are reset to their default values.
