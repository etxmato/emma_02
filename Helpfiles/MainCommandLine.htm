Options valid for all command line cases: 

-h,  --help            Show command line help message
-p,  --portable        Run in portable mode (see below)
-u,  --skip update     Skip update check
-w,  --window          Non-fixed window positions (see the Window Settings section)
-ns, --nosplash        Do not show splash screen (help) on start
-c,  --computer=<str>  Start emulation without GUI for specified computer

Options only valid when -c is specified: 

-v,  --verbose         Verbose output
-f,  --fullscreen      Full screen mode
-x,  --XML=<str>       Load specified XML file on start
-s,  --software=<str>  Load specified software on start
-r,  --run=<str>       Run specified software on start
-ch, --chip8=<str>     Load specified Chip-8 software on start
-st, --st2=<str>       Load specified Chip-8 software on start
-s0, --software0=<str> Load binary software in GUI slot 0 on start
-s1, --software1=<str> Load binary software in GUI slot 1 on start

Note: The equal sign is optional in the above commands. All commands where software files are specified can either include the full path (c:gamesinvaders.st2) or just the file name. If only a file name is used, Emma 02 will try to load the game file from the directory specified in the used XML file.

Specify -s="" (for a Studio II, Studio III, Conic, MPT-02 or Visicom COM-100) to start without an st2 file loaded, i.e., to run the emulator with the built-in games. This will result in the same behavior as not using a -s or -st option.

In portable mode (-p) the emulator can run from any location and will expect all data and setting files in the subdirectory "data" in the application directory (wherever the Emma 02.exe file is located). The first time option -p is used, all directory entries in the .ini file will be set to the application directory on startup. Also, if the "data" directory does not exist, it will be created.

Examples:

Command:

"Emma 02" -p -c=tmc2000 -s chip8.ram -ch "Landing.ch8"

Result: Starts a TMC2000 with Chip-8 and Chip-8 game Landing.

Command:

"Emma 02" -p -c=comx -r "C:Emma 02dataComxGamesHappieHap 2.comx"

Result: Starts Happiehap 2 (pac man clone) on the COMX, assuming the specified Emma 02 path is correct.

Command:

"Emma 02" -p -c=victory -s invaders.st2

Result: Starts Victory Invaders, assuming the Victory directory is set to default.

On game computers such as Studio II and Cidelsa, -s is the same as -r. For others such as the COMX, -s only loads the software but does not run it like -r.

When using the command line on macOS the executable is stored in: 

/Applications/Emma 02.app/Contents/MacOS/

To start a COMX with Happiehap 2: 

/Applications/Emma 02.app/Contents/MacOS/Emma 02 -c=comx -r "/Users/your user/Documents/emma_02/Comx/Games/Happiehap 2.comx"
