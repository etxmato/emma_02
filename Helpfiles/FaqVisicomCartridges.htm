How do I play the Visicom COM-100 cartridge games?

This section includes short instructions for some of the dumped Visicom cartridge files.

The descriptions below assume you are using a numeric keypad and have selected Settings/Use Numeric Keypad. If this option is not selected, the alternative key is shown in parentheses. For Player B, the keys W, A, S, Z control direction and TAB is used to fire. These keys work both with and without the Use Numeric Keypad setting enabled.

cas-130

Baseball

Press 0 to start. Player A bats first and Player B pitches. The pitching player attempts to catch the ball by moving the fielders. Player A and Player B alternate every half inning.

Controls

Batting

Player A
--------
SPACE              swing bat

Player B
--------
Numpad 5 (TAB)     swing bat

Pitching

Player A
--------
Up Arrow           inside curve
SPACE              straight pitch
Down Arrow         outside curve

Player B
--------
Numpad 8 (W)       inside curve
Numpad 5 (TAB)     straight pitch
Numpad 2 (Z)       outside curve

Moving Fielders

Player A
--------
Up Arrow           move up
Down Arrow         move down

Player B
--------
Numpad 8 (W)       move up
Numpad 2 (Z)       move down

Hold the key down for 1/4 second for a change-up (slow ball).

Sumo Wrestling

Press SPACE to start. Then press 0 and Numpad 0 (P) to perform the initial charge.

Controls

Player A (left)
---------------
Right Arrow        push
Left Arrow         pull
SPACE              throw

Player B
--------
Numpad 4 (A)       push
Numpad 6 (S)       pull
Numpad 5 (TAB)     throw
