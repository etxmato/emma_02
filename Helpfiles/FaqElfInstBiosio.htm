How do I change to Biosio after Elf/Os 2.8 installation?

This instruction describes how to install and use Biosio with Elf/Os. For installation of Elf/Os, please follow the FAQ How do I install Elf/Os 2.8 on an Elf?. For details on how to use Biosio with other applications, see the .txt files in the Biosio directory.

The "BIOS Video I/O Module" is designed by Richard Peters. This version allows the use of Elf/Os on different video types such as CDP1861 Pixie, MC6845, MC6847, and TMS9918.

To install the Biosio routines use the following settings:

Biosio configuration

ROM 1: bios+biosiov93.rom 
(ROM 1: bios+biosiov93_32.column.rom for MC6847) 
RAM 2: xxxINIZ.rom (where xxx is the required I/O)
IDE: (any filename).ide
Disk Type: IDE; with 512 Tracks, 4 Heads and 26 Sectors
Boot address: FF00
RAM: 0 to FFFF
Video: (needed I/O)
Keyboard: ASCII Keyboard
VT100: selected
Uppercase: selected

Command:

Press Start
Press Return in the VT100 window

Result: Elf/Os will start in the VT100 window.

When Elf/Os has started use the SAVE command with the details below for the required I/O configuration:

CDP1861 Pixie:

START address: 7000 
END address: 706F 
EXEC address: 7041 
FILE NAME: PIXINIZOS

MC6845/MC6847 Video:

START address: 7000 
END address: 7062 
EXEC address: 7035 
FILE NAME: VIDINIZOS

TMS9918, text mode:

START address: 7000 
END address: 768F 
EXEC address: 7088 
FILE NAME: TMSINIZOS

TMS9918, graphic mode:

START address: 7000 
END address: 748F 
EXEC address: 70A2 
FILE NAME: GRAINIZOS

VT100 (without baud check):

START address: 7000 
END address: 708F 
EXEC address: 7035 
FILE NAME: SERINIZOS

To switch input and video, start the xxxINIZOS file corresponding to the desired video system.

Important: To start Elf/Os on one of the Biosio video systems copy the desired xxxINIZOS file to INIT.

When using the ASCII keyboard the input port and EF flag settings should be changed as follows:

Keyboard settings

MC6845 Video Card
Keyboard Input Port: 5, EF Flag: 4

Pixie Video and TMS9918 Video
Keyboard Input Port: 7, EF Flag: 3
