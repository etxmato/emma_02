How do I load a program using the LOAD button?

The example shows the Memory configuration and Memory Access sections in the Computer tab:

  • (1) RAM file loaded at address @0000
  • (2) ROM file loaded at address @8000
  • (3) LOAD button in the Memory Access section

There are multiple ways to load software into an emulated computer. Choose one of the following options depending on your needs or preference.

  1. For loading software before the computer starts, use the ROM (2), RAM (1), or NVR buttons. See the ROM, RAM, NVR section.
  2. For loading software directly into the emulated computer after startup, use the LOAD button (3) in the Memory Access area:

All load buttons (1, 2, 3, and NVR) load a binary file into the emulated computer's memory. If specified, the file will be loaded starting at the Start address.

For more details, see the Memory Access section or:

  1. For loading software using the emulated computer's cassette interface, see the Cassette Support section.
  2. For loading software using the emulated computer's disk interface, see the Disk Support section.
